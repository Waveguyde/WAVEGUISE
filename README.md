# WAVEGUISE
**WAVefield analysis and sEGmentation Unraveling an Interpretable SEt of wave packets**\
This package builds upon the continuous wavelet transform (https://jugit.fz-juelich.de/j.ungermann/juwavelet.git) as described in Ungermann and Reichert (2025) as well as the watershed segmentation algorithm included in the scikit-image Python package and the density based spatial clustering with noise (DBSCAN) and separates a wavefield of up to three dimensions into a set of interpretable wave packets. 

Please contact robert.reichert@dlr.de for assistance. A corresponding publication is submitted at Atmospheric Measurement Techniques.
